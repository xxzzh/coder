# 报告风格参考

当用户要求润色项目更新、周报、计划备忘录或事故状态记录时，使用这份参考。

## 表达口吻

- 使用直接、清楚的业务表达。
- 先写当前状态，再写背景。
- 保留不确定性：用“被……阻塞”“等待……确认”“当前未知”等表达，不要用模糊乐观的语气掩盖风险。
- 避免营销式表达和不必要的形容词。

## 行动项

每个行动项都应该包含：

- 负责人：具体个人、团队，或 `TBD`。
- 动作：明确的动词短语。
- 日期：已知时写准确日期，未知时写 `TBD`。

格式：

```markdown
- [ ] <负责人> - <动作> - <YYYY-MM-DD 或 TBD>
```

## 风险条目

有效的风险条目应包含影响和缓解措施：

```markdown
- <风险>。影响：<如果风险发生会改变什么>。缓解措施：<当前应对方式>。负责人：<负责人>。
```
